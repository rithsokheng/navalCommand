Place your audio files here. Supported formats: MP3, WAV, M4A, AAC.

Music (looping background):
  menu-music.mp3   - Main menu / placement screen background music
  battle-music.mp3 - Battle screen background music

Sound Effects (one-shot):
  click.mp3        - UI button click
  fire.mp3         - Weapon fired
  hit.mp3          - Shell hits enemy ship
  miss.mp3         - Shell misses (splash)
  sunk.mp3         - Enemy ship sunk (explosion)
  nuclear.mp3      - Nuclear weapon launch
  place-ship.mp3   - Ship placed on grid
  remove-ship.mp3  - Ship removed from grid
  victory.mp3      - Victory fanfare
  defeat.mp3       - Defeat stinger
  turn-start.mp3   - Your turn begins

All files are optional. The game works without them.
SoundManager silently ignores any missing file.
